# 开发者福利线报模块

## 热榜与热度

- “全部线报”按所选排序展示所有记录，并明确标记未核验的预置示例。
- “社区热榜”只展示有真实互动指标且达到上榜门槛的采集记录；预置示例不进入热榜和热榜数量统计。
- 可用指标为点赞、回复、浏览量。来源没有提供某项指标时使用 0 存储、在界面显示“—”，禁止用估算值冒充真实互动。
- 热度指数先计算 `原始分 = 10×(点赞×3 + 回复×2 + 浏览×0.05)/(已过小时数+2)^1.5`，再通过 `100×原始分/(原始分+100)` 归一化到 0–100。无互动数据时不显示热度。
- 热榜门槛为归一化热度指数不低于 `12`；不因任一单项互动数较高而绕过综合评分门槛。
- 搜索条件必须与来源、分类和热榜条件组合计算，响应总数与分页采用同一筛选条件。

## 线报 AI 助手

- `POST /admin/api/v1/deals/chat` 接受最近最多 12 条 `user` / `assistant` 消息及可选 `web_search` 开关，返回 Markdown `answer`。
- 默认开启联网搜索；联网模式固定使用支持 `search` 提示的 ChatGPT 号池，关闭后可使用现有自动模型路由。
- 提示词把已采集的非示例线报作为背景，并要求模型核查时效信息、区分已核验内容与社区线索、附上联网来源链接。
- 对话暂存于浏览器当前页面状态，不写入服务器对话历史。
