# 短剧工坊新一代无限画布 (Cinematic Infinite Canvas V2) 深度设计与调研方案

> 本方案深度调研了目前业界最成熟优秀的 6 款无限画布与影视创作产品（ComfyUI、Runway Gen-3/Pika、Higgsfield、Leonardo.ai/Midjourney、Figma/Miro、剪映/CapCut），并针对当前 `ai-web-free` 短剧创作工坊的痛点提出系统化、电影工业级的重构方案。

---

## 一、业界优秀成熟无限画布深度调研与对照

| 调研产品 | 核心设计哲学与交互特性 | 对短剧工坊的借鉴与落地点 |
| :--- | :--- | :--- |
| **ComfyUI**<br>*(AI生成拓扑之王)* | 1. **强类型端口插槽**：严格区分 MODEL, IMAGE, LATENT, AUDIO 端点，以专属颜色标识，从物理上杜绝非法连线。<br>2. **流水脉冲动画**：执行中数据流线产生沿路径运动的动态发光粒子（Flowing dashoffset）。<br>3. **节点折叠与重塑**：节点支持双击折叠为极简 Pill 胶囊，大幅释放视口空间。 | • **端口插槽系统**：角色参考端口（紫色）、场景背景端口（天青）、分镜时序连线（暗金）、终点装配端口（祖母绿）。<br>• **数据流动可视化**：执行中的节点连线带有光斑脉冲，清晰展示数据流向。<br>• **智能连线过滤**：支持“全量展示”与“仅选中聚焦（Focus on Selected）”一键切换。 |
| **Runway Gen-3 / Pika / Sora**<br>*(电影级AI生成)* | 1. **镜头语言结构化**：每个 Shot 具备标准的景别（特写/全景）、运镜（推拉摇移）、帧率与时长属性。<br>2. **首尾帧时序锚定**：首帧图驱动 + 结尾帧衔接保证多镜头平滑过渡。 | • **影视胶片卡片**：顶部胶片齿孔与景别/运镜标签。<br>• **独立三态指示灯**：卡片上分别显示首帧生图、TTS 配音音频、视频生成的独立耗时与状态。 |
| **Higgsfield / Krea AI**<br>*(创作者画板与分支比对)* | 1. **平行分支比对 (Branching/Versioning)**：同一镜头支持 V1/V2/V3 平行生成并一键切换 Active 版本。<br>2. **局部按需重绘 (Selective Regenerate)**：不重置下游的前提下仅重跑配音或微调首帧。 | • **分镜卡片 A/B 分支切换器**：直接在节点卡片顶部选择 vA（主推）与 vB（冷调备选），不打乱整体拓扑。<br>• **模块化独立重跑**：支持“仅重跑配音”、“仅重绘首帧”、“仅重跑视频”。 |
| **Figma / FigJam / Miro**<br>*(设计界无限视口天花板)* | 1. **LOD 多级视口自适应 (Level of Detail)**：<br>- 视口 >80%：全精细可编辑卡片；<br>- 视口 40%~80%：中景缩略卡片；<br>- 视口 <40%：宏观胶囊与状态呼吸灯，避免几千 DOM 节点卡顿。<br>2. **悬浮灵动岛 (Dynamic Island HUD)**：居中悬浮指挥舱，不遮挡核心工作区。<br>3. **平滑阻尼手感**：惯性平移与智能吸附导线。 | • **LOD 三级视口降级体系**：放大时看台词与提示词，缩小时自动收敛为影视色块与状态脉冲灯，大剧集（30~100镜头）依然极其流畅。<br>• **中央悬浮灵动岛 HUD**：展示进度环、耗时预估与全局一键成片状态。<br>• **右侧抽屉式导演监视台 (Inspector)**：点击节点平滑滑出，不占用画布常驻横向空间。 |
| **剪映 (CapCut) / Premiere**<br>*(非编视频时间轴标杆)* | 1. **空间画布与时间线性多轨双向映射**：空间负责逻辑与资产，底部时间线负责成片节奏。<br>2. **播放头定位 (Playhead Scrubbing)**：拖动播放头可直接预览连续画面。 | • **底部影视级多轨时间线 (Dual Canvas-Timeline Bridge)**：包含视频轨、配音轨、BGM背景乐。<br>• **双向联动**：点击时间线镜头，画布平滑飞行动画聚焦该节点；点击画布分镜，时间线播放头同步跳转。 |

## 二、短剧工坊当前痛点与 V2 破局对比

| 维度 | 当前现有版本（痛点） | 新一代 V2 设计规范（升级） |
| :--- | :--- | :--- |
| **视觉基调** | 偏浅色/高饱和度白底，多色边框跳脱，缺乏电影创作的暗房沉浸感与专业工业感。 | **电影暗房极夜质感 (`#090B10` & Zinc-950)**，搭配低反光网格点阵、微发光边框（Glow Border），极佳的视觉聚焦度。 |
| **连线体验** | 节点间连线过多交叉如“蜘蛛网”，无端点语义，缩放后混乱。 | **ComfyUI 风格语义端点**：左右类型化插槽（端口小圆孔），连线采用高阶贝塞尔曲线，并附带执行脉冲动画与“聚焦过滤”模式。 |
| **卡片信息架构** | 卡片偏臃肿，各种错误文本混排，缺乏影视层级。 | **影视胶片卡片 (Filmstrip Card)**：统一 16:9 / 9:16 自适应预览窗口、景别运镜 Badge、独立三状态小药丸（首帧/音频/视频）。 |
| **多版本决策** | 只能单线重试，无法对比生成效果。 | **内置 A/B/C 分支选择器**：每个镜头可保留多套生成结果，支持一键切换 active 版本。 |
| **时间感知与预览** | 只有分散的节点，不知道成片拼起来整体节奏如何。 | **集成底部影视 4 轨时间线 (Mini-Timeline)**：视频轨 + 台词轨 + 音乐轨，支持空格键全片连贯试看与剪映工程一键导出。 |
| **视口层级 (LOD)** | 缺乏视口缩放等级优化，缩小时字迹模糊重叠，放大切割。 | **LOD 智能视口自适应**：缩放比例小于 65% 时自动平滑折叠细枝末节，仅保留缩略图、分镜号与状态呼吸灯。 |

## 三、V2 原型功能验证清单

在交付的高保真交互原型 `drama_canvas_v2_prototype.html` 中，已完整实装以下交互验证点：
1. **画布视口与手感**：
   - 鼠标滚轮顺滑缩放（支持以光标位置为中心缩放）。
   - 按住空白处自由拖拽平移，画布背景微弱点阵自适应。
2. **LOD 多级视图切换**：
   - 点击右上角缩放调节或“LOD 模式切换”按钮，体验精细影视卡片与紧凑宏观视图的自适应切换。
3. **ComfyUI 风格智能连线与流动脉冲**：
   - 角色输出端（紫色/粉色）-> 分镜输入端（琥珀金）-> 成片终点（翡翠绿）的带语义连线。
   - 渲染中分镜连线带有高亮动态流动粒子效果。
   - 顶栏支持“全部连线”与“仅选中聚焦”实时切换。
4. **胶片分镜卡片与 A/B 分支切换**：
   - 分镜卡片顶部带有电影齿孔设计与运镜标签。
   - 分镜 #01 支持点击切换 `vA` 与 `vB` 版本。
   - 悬浮卡片可点击“播放分镜”，即时打开大屏成片播放预览模态框。
5. **底部多轨时间线与画布双向映射**：
   - 点击时间线任意镜头，播放头跳转且画布自动平滑飞行动画聚焦（Fly-to Node）到对应分镜节点。
   - 点击“播放全片”，时间线播放头持续平滑推进。
6. **右侧导演监视台抽屉 (Director's Inspector)**：
   - 选中任意角色、场景或分镜节点，右侧平滑滑出抽屉，可实时微调运镜、台词语速、Prompt 并查看局部 Trace 执行日志。
7. **全流程成片模拟调度**：
   - 点击右上角“✦ 一键全流程成片”，灵动岛 HUD 进度环实时推进，#03 镜头从渲染中平滑过渡到 100% 成功，全片状态胶囊即时响应。
