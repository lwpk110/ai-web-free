## 一、后端「赛道 1 · 生产级号池运维闭环」设计

严格保持 **`CGO_ENABLED=0` 纯静态 Go 编译**（兼容 [Dockerfile](file:///home/luwei/workspace/github/ai-web-free/Dockerfile) 的 `distroless/static-debian12:nonroot`），不引入任何外部数据库或三方语言运行时。

### 1. 卡密账号后台单队列自动续期（[bootstrap.go](file:///home/luwei/workspace/github/ai-web-free/internal/bootstrap/bootstrap.go) / [chatgpt_plugin.go](file:///home/luwei/workspace/github/ai-web-free/internal/provider/chatgpt_plugin.go)）
- **触发条件**：`StartHealthCheck` 巡检发现包含卡密凭据（`Email + Password + TOTPSecret`）且无 `RefreshToken`/`SessionToken` 的账号处于 `StatusExpired`（含请求 401 标失效），或距 `ExpiresAt` 不足 `24h`。
- **串行防风控队列**：
  - 独立单消费者 goroutine + 去重入队队列（同一时间最多启动 **1 个** 无头 `chromedp` 实例），避免并发拉起多个 Chrome 导致 OOM 与风控。
  - 为每个卡密账号增加 `RenewCooldownUntil` 与连续失败退避（5m → 30m → 2h），并在 `AccountSnapshot` 中暴露 `renew_state`（`idle | queued | renewing | backoff`）。
  - 续期成功后自动同步 JWT 元数据，更新 `StatusActive` 并原子持久化写回 `access_tokens.txt`。

### 2. 全链路请求 Failover 与分级 429 冷却状态机（[pool.go](file:///home/luwei/workspace/github/ai-web-free/internal/accounts/pool.go) / [image_handler.go](file:///home/luwei/workspace/github/ai-web-free/internal/handler/image_handler.go) / [chat_handler.go](file:///home/luwei/workspace/github/ai-web-free/internal/handler/chat_handler.go) / [audio_handler.go](file:///home/luwei/workspace/github/ai-web-free/internal/handler/audio_handler.go)）
- **分级限流字段（扩展 `Account`）**：
  - 区分 **全能力冷却**（`CooldownUntil` + `StatusRateLimited`）与 **仅生图配额冷却**（`ImageCooldownUntil`，不影响同一账号继续提供文本对话）。
