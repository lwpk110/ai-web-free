## 2. 决策树访谈记录 (Decision Drivers & Grill-Me Q&A)

#### 决策分支 1（单选）：针对项目从本地 SQLite 演进到云端托管 PostgreSQL，你倾向首选哪款免费云 PG 服务商？

候选方案：
- (Recommended) Neon (Serverless Postgres: 免绑卡极速创建、0.5GB免费容量、支持连接池，冷启动约500ms唤醒，适合多端轻量直连)
- Supabase (功能最全：500MB免费存储、内置控制台与连接池，但闲置7天无请求会暂停需心跳保活)
- Aiven for PostgreSQL (最稳不休眠：提供真正常驻不暂停的免费云PG节点，单实例1GB内存+5GB存储)
- 其他/自建方案 (如 CockroachDB Serverless 或通过现有 VPS 部署自建单机 PG)

> **已选决策**：(Recommended) Neon (Serverless Postgres: 免绑卡极速创建、0.5GB免费容量、支持连接池，冷启动约500ms唤醒，适合多端轻量直连)

#### 决策分支 2（单选）：在数据库驱动架构上，你希望如何规划 PostgreSQL 与现有 SQLite 的关系？

候选方案：
- (Recommended) 双驱动兼容模式（根据 DATABASE_URL 前缀动态路由：postgres:// 走 Neon PG，未配置或以 .db 结尾走本地 SQLite 兜底）
- 纯 PostgreSQL 模式（彻底移除本地 SQLite 依赖，项目必须配置 Neon PG 连接串才能启动）

> **已选决策**：(Recommended) 双驱动兼容模式（根据 DATABASE_URL 前缀动态路由：postgres:// 走 Neon PG，未配置或以 .db 结尾走本地 SQLite 兜底）

#### 决策分支 3（单选）：切换至 Neon PG 后，本地 SQLite 中已有的 110 个账号及历史画廊/会话数据如何迁移到云端？

候选方案：
- (Recommended) 启动时自动无缝迁移（首次连上云端 PG 且目标库为空时，自动检测本地 data/ai-web-free.db 并全量灌入云端 PG）
- 显式命令迁移（通过 make migrate 或 ./ai-web-free -migrate 手动触发单次数据搬迁）
- 全新初始化（不搬迁本地旧数据，直接以全新云端 PG 数据库运行）

> **已选决策**：(Recommended) 启动时自动无缝迁移（首次连上云端 PG 且目标库为空时，自动检测本地 data/ai-web-free.db 并全量灌入云端 PG）

#### 决策分支 4（单选）：接入 Neon PG 后，原有的七牛云 make backup / restore 备份流水线如何定位？

候选方案：
- (Recommended) 轻量一体化（云端 PG 自身由 Neon 提供实时持久化与灾备；七牛云仅负责多媒体文件与 .env 备份，多端直连同一 PG 彻底免除跨机恢复 DB）
- 双保险容灾（多端直连 Neon PG 的同时，make backup 仍将云端 PG 中的全量账号与数据导出快照备份到七牛云作为冷归档）

> **已选决策**：(Recommended) 轻量一体化（云端 PG 自身由 Neon 提供实时持久化与灾备；七牛云仅负责多媒体文件与 .env 备份，多端直连同一 PG 彻底免除跨机恢复 DB）

### 二、已收敛的核心架构决策

1. **首选服务商**：选定 **Neon Serverless PostgreSQL**。
   - 获取一个形如 `postgres://alex:secret@ep-xyz-pooler.ap-southeast-1.aws.neon.tech/neondb?sslmode=require` 的连接串即可全局共享。
2. **双驱动兼容路由器（GORM Dual-Engine）**：
   - 保持严格零 CGO（`CGO_ENABLED=0`）约束：PostgreSQL 驱动采用纯 Go 的 `gorm.io/driver/postgres`（基于 `jackc/pgx/v5`）；
   - 当 `DATABASE_URL` 以 `postgres://` 或 `postgresql://` 开头时连接云端 Neon PG；
   - 未配置或指向 `.db` 时，平滑降级为本地纯 Go SQLite（`glebarez/sqlite`），本地开发与测试依然开箱即用。
3. **启动期自动无缝自愈迁移**：
   - 系统首次连上云端 PG 时，若检测到 PG 的号池表为空且本地存在 `data/ai-web-free.db`，会自动将本地现有的全部 110 个账号、代理绑定及历史会话/画廊数据批量灌入云端 PG，做到零人工干预迁移。
4. **轻量协同运维分工**：
   - 多机部署（旧电脑、新电脑、Docker 节点）只需在 `.env` 中配置相同的 `DATABASE_URL`，所有节点直接共享同一个号池，彻底免去跨机 `make backup` / `make restore` 数据库的繁琐操作；
   - 七牛云专精于承载大体积多媒体文件（`TieredStorage`）与 `.env` 快照。
